# EMPTY prospective forms

The nine CSV files in this folder contain headers and zero observation rows. They describe records needed for future physical scale, independent references, repeated annotation/acquisition and empirical uncertainty work in Supplementary Information S7–S8. status_manifest.json records their missing-data status.

These forms are not completed experiments. Do not fill unknown quantities with zero, transfer units from another dataset, treat deterministic reruns as independent repetitions, or recast interpolated/automatic points as manual observations. The unmodified source records remain outside this export.
